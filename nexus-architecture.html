Architectural Details & Specifications

4 Structured Detail Cards
Primary Path
Request Dispatch Lifecycle
Path: Browser → Nginx → FastAPI → Simulation Engine → Algorithm Registry → Virtual Server Nodes.

The engine runs an asynchronous tick loop generating synthetic traffic根据 current traffic mode (slow, normal, heavy, burst) and routes each payload to active nodes through the selected strategy.
Component Detail
Raft Consensus Control Plane
Simulates a 3-node distributed consensus cluster maintaining active leader election, heartbeat intervals (150ms-300ms), and term numbers.

If the active leader node is killed via the dashboard, client requests are dropped until candidate voting finishes and a new quorum leader emerges.
Component Detail
Telemetry & Real-Time Broadcast
MetricsCollector computes moving-average requests-per-second, 95th-percentile latencies, CPU distribution, and server health.

Instead of polling, the WebSocket Broadcaster pushes state snapshots every tick to all connected browser clients.
Trust Boundaries & Cloud Integration
Security & External Dependencies
Trust Boundaries: Untrusted client browser sessions are terminated at Nginx and FastAPI.

External Dependency: The only third-party dependency is the Resend API, called over outbound HTTPS by the feedback router to dispatch administrator alert emails.
